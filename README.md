# Reyhan Salman — Portfolio

The portfolio is designed around the idea of being a multidisciplinary engineer — exploring different areas of technology while focusing on building complete, useful systems.

## Featured Projects

### Signora
A vision-and-language system for sentence-level Indonesian Sign Language (BISINDO) translation using MediaPipe, CNN-GRU, and Bahdanau Attention.

### Aequilibria
An NLP-powered journaling application using TF-IDF and XGBoost to analyze patterns in journal entries through an interactive visualization experience.

### MAHA — My Assistant Health App
A personalized digital health platform developed for the Bangkit Product Capstone 2024, combining mobile development, machine learning, and Google Cloud infrastructure to provide adaptive diet and exercise recommendations.
